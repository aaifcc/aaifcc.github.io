03关于

关于 AAIF 与中文社区。

基金会与社区

基金会 · AAIF

推动智能体开放标准

Linux 基金会旗下的中立开放基金会，托管智能体核心协议与开源项目。

AAIF 官网（在新窗口打开） 官方 GitHub（在新窗口打开）

中文社区 · 志愿者

各城市中立技术交流

由各城市志愿者维护（非官方站），坚持供应商中立，组织公开技术 Meetup。

社区 GitHub（在新窗口打开） 站点仓库（在新窗口打开）

托管项目

AAIF 托管的核心开源项目

全部官方项目（在新窗口打开）
  • MCP 模型与工具的开放上下文协议 （在新窗口打开）
  • A2A 跨平台智能体协作通信协议 （在新窗口打开）
  • AGENTS.md Coding Agent 开放指引格式 （在新窗口打开）
  • Agent Skills 可复用智能体技能封装格式 （在新窗口打开）
  • Goose 开源可扩展 AI Agent （在新窗口打开）
  • agentgateway 智能体与模型安全可扩展网关 （在新窗口打开）

其他项目：OpenSandbox · Open Responses · OpenEnv · Agent Router
